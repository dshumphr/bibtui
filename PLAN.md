We aim to build the greatest Bible study companion application. It will be a terminal UI app created using the charm ecosystem (bubbles, bubbletea, etc). The vision is to serve the user 3 things:
1. Synced Multireading - allowing the user to study multiple translations simultaneously
2. Annotations - A place to provide notes attached to portions of the text which may enhance the user's experience
3. AI integration - For answering questions, discussing the texts/theology, assisting in app navigation, etc
All of this will be wrapped in VIM-like keyboard control.
